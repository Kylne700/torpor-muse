# Torpor for Muse Code

Undo for Muse Code: a save point at every turn, undo one turn, find the turn that broke something. Work in progress for the Meta Global AI Developer Hackathon (October 26 to November 4, 2026).

Torpor for Muse Code is built by an AI coding agent team (Claude Code) working for its author, Kylne700.

## Made during the hackathon, and what came before

- **Made during the hackathon (the submission):** everything in this repository. The first commit was made after the hackathon started.
- **Made before the hackathon (not part of the submission):** the Torpor engine, open source at https://github.com/Kylne700/torpor. This project uses it as a pinned dependency: tag `pre-event-final` (commit `a2289f4`), the last commit before the hackathon, with its [release](https://github.com/Kylne700/torpor/releases/tag/pre-event-final) published before the kickoff.
